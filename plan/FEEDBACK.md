# 專案經驗回饋紀錄 (FeedBack)

本文件用於收集本專案執行過程中累積的改善建議與經驗洞察。經評估後，具備高通用性的回饋可合併回通用模板 (`AiProjectTemplate`)，使模板持續演進。

> **本檔案為選用檔案**：若本專案不需要回饋機制，可安全刪除此檔案而不影響其餘模板功能。

---

## 回饋流程

```
發現問題/改善點 → 記錄至本檔案 → 與使用者討論確認
→ 評估通用性 → 由使用者決定是否合併回模板
```

---

## 回饋狀態定義

| 狀態 | 說明 |
| :--- | :--- |
| `待評估` | 已記錄，尚未與使用者討論 |
| `已確認-待執行` | 使用者同意納入，等待執行 |
| `已處理-成功加入` | 已成功合併回模板或本專案 |
| `已處理-已有定義` | 經檢查，模板中已有等效的機制覆蓋 |
| `已處理-註銷` | 經討論後決定不採納（附理由） |

---

### FB-001 [簡短描述此回饋的標題]
